# AGENTS.md

This repository's agent instructions live in **`CLAUDE.md`** at the repository root. Read it in full before performing
any task, then follow its document routing table in §4 to load the specific knowledge file for the task at hand.

Do not begin writing Solidity or TypeScript until you have read:

1. `CLAUDE.md` — operating rules and non-negotiable invariants
2. `docs/03-fhevm-knowledge.md` — the FHE programming model and forbidden patterns
3. `docs/API-VERIFIED.md` — the verified API surface, and the rule for adding to it

Everything else is loaded on demand.
