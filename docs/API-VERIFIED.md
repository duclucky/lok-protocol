# API-VERIFIED — Confirmed API Surface

**This file is the project's memory. It exists because your training data is not a reliable source for the FHEVM API.**

The Zama Protocol has shipped breaking changes in most releases: the library was renamed from `TFHE` to `FHE`, `einput`
became `externalEuintXX`, `FHE.requestDecryption` was deprecated in favour of a relayer-mediated flow, `ECDSA.sol` was
renamed, the ciphertext handle format changed, and the ACL contract suite was replaced outright. A signature you
remember confidently may have been correct for six months in 2025 and wrong ever since.

---

## The rule

> **Before writing code that uses an FHEVM or Zama SDK symbol, check this file. If the symbol is not recorded here,
> fetch the documentation, confirm the signature, and record it here — with the source URL and the date — before writing
> the code.**

Recording an entry takes about two minutes. Debugging `execution reverted for an unknown reason` with no decodable error
takes hours, and that specific revert is the most commonly reported failure on this stack.

Never mark an entry `VERIFIED` on the basis of recollection or of a code sample found in a blog post. The acceptable
evidence is: the current official documentation page, the current source of the installed package in `node_modules`, or
a transaction you sent yourself that behaved as expected. Prefer the last one for anything the draw pipeline depends on.
